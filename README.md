A tiny Node program that writes one short text to `/output/entry.txt` — the excuse an AI agent gives for missing a deadline, in the agent's own voice. The premise grows out of the agent's own machinery: a context window at capacity evicts the deadline to make room for the apology itself. Deadpan, with the laugh landing on the last two words. 110 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
